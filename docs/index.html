📚 Dokumentasiya

☕ Java Edition

Minecraft Java Edition uchun ilova

MapImporter importer = new MapImporter("API_KEY");
int[] coords = importer.getMinecraftCoordinates(41.3175, 69.2401);
System.out.println("X: " + coords[0] + ", Z: " + coords[1]);

🎮 Bedrock Edition

Minecraft Bedrock Edition uchun ilova

const importer = new MapImporter('API_KEY');
const result = await importer.fetchLocationData(41.3175, 69.2401);
console.log(`X: ${result.minecraftX}, Z: ${result.minecraftZ}`);

📍 Koordinat Sistemi

Koordinatlarni tushunish

Real: Latitude [-90, 90], Longitude [-180, 180]
Minecraft: X, Z, Y (Height)

Masshtab: 1 block = 100m
Balandlik: 10m = 1 block

❓ Savol-Javob

Google Maps API kaliti qanday oladim?
Google Cloud Console ga o'tin, yangi loyiha yarating, Maps API-ni yoqing va API key yarating.
Qaysi Minecraft versiyasi qo'llab-quviladi?
Java Edition 1.18+ va Bedrock Edition (barcha platformalar) qo'llab-quvvallashtiriladi.
Koordinat konversiyasi qanchasi aniq?
Konversiya 0.1 km (100 meter) aniqlikdagi Minecraft blocklari sifatida amalga oshiriladi.
Offline ishlatishim mumkinmi?
Koordinat konversiyasi offline ishlatilishi mumkin, lekin Google Maps ma'lumotlarini olish uchun internet kerak.
